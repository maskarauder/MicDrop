# MicDrop 0.1.0-beta.4 — Signed Windows & macOS packaging, TestFlight iPhone pipeline, and multi-platform beta

This candidate introduces cloud code signing and notarization pipelines for
Windows 11 x64, Apple Silicon macOS 14.2+ arm64, and iPhone iOS 17+ arm64
alongside Linux x64 and Android 12+ arm64. Build, package, and smoke-test this
candidate before sharing; check the generated **Package signing** line below and
each platform's `MicDrop-0.1.0-beta.4-*-build.json` manifest for verified
signing and notarization status.

## Included in this candidate

- **Windows 11 x64 Authenticode signing pipeline (`MicDrop-<version>-windows-x64-setup.exe`
  and `MicDrop-<version>-windows-x64-portable.zip`)**: Four-stage Microsoft Azure
  Artifact Signing + RFC 3161 timestamping across `MicDrop.exe`,
  `micdrop_rtc.dll`, `MicDrop-maintenance.exe`, `unins000.exe`, and the per-user
  installer when CI signing credentials are configured, with `Get-AuthenticodeSignature`
  verification recorded in `MicDrop-<version>-windows-build.json`.
- **macOS 14.2+ Apple Silicon Developer ID signing & notarization (`MicDrop-<version>-macos-arm64-app.zip`
  and `MicDrop-<version>-macos-arm64-host.tar.gz`)**: Custom bundled `AppIcon.icns`,
  ephemeral keychain `Developer ID Application` signing with Hardened Runtime and
  secure timestamps, Apple notarization (`xcrun notarytool`) with stapled ticket
  and Gatekeeper `spctl --assess` verification when configured, and verified
  `codesign` / `stapler` metadata recorded in `MicDrop-<version>-macos-build.json`.
- **iPhone iOS 17+ (`com.maskarauder.micdrop`) app icon, TestFlight archive, and
  optional unsigned sideload IPA (`MicDrop-<version>-ios-arm64-unsigned.ipa`)**:
  Migrates the iPhone bundle identifier to `com.maskarauder.micdrop`, bundles a
  verified 1024x1024 RGB `AppIcon.png`, and adds `Apple Distribution` signing and
  optional App Store Connect / TestFlight upload alongside the unsigned sideload
  archive.
- **Linux x64 desktop and CLI host (`MicDrop-<version>-linux-x64-host.tar.gz`)
  and Android 12+ arm64 (`MicDrop-<version>-android-arm64-dev.apk`)**: GTK3
  desktop GUI + PipeWire/PulseAudio CLI host on Linux, and matching slate/gold
  Android client with paired LAN/remote streaming, microphone return, and
  diagnostics.
- **Verified release provenance**: `tools/draft_release.py` inspects actual
  binary signatures and notarization tickets during staging and generates the
  release's `Package signing:` summary directly from verified `*-build.json`
  manifests.
- MPL-2.0 license and third-party dependency notices in every packaged archive
  and application bundle.

Android version code is **5** (and macOS/iPhone `CFBundleVersion` is **5**).
Android retains `com.maskarauder.micdrop.dev` with its stable development
signing key so existing beta APK installations update in place without losing
pairings or settings; `MicDrop.app` on macOS uses `com.maskarauder.micdrop.mac`,
and iPhone uses `com.maskarauder.micdrop` (iPhone users updating from an earlier
`com.maskarauder.micdrop.dev` sideload should pair once under the new bundle ID
and remove the old `.dev` app).

## Before testing

Install or extract the matching desktop host package for your computer
(Windows setup or portable ZIP, Linux x64 `.tar.gz`, or macOS arm64
`MicDrop.app` ZIP / CLI `.tar.gz`) together with the matching Android APK,
TestFlight iPhone build, or sideloaded unsigned iPhone IPA from this candidate.
Follow `BETA_TESTING.md` and `README.md` for platform-specific setup.

Start with local-network playback on the phone speaker, then try your
headphones. Phone microphone return requires a virtual audio cable (such as
VB-CABLE on Windows, BlackHole on macOS, or a PipeWire/PulseAudio null sink +
remap source on Linux) and explicit microphone permission on the phone.

## Known limits

- Newly issued Windows Authenticode certificates build Microsoft SmartScreen
  download reputation gradually and may still display an initial reputation
  prompt until download volume accrues; Linux x64 archives remain unsigned.
- Android is a sideloaded, debuggable development build, not a Play Store release.
- Sideloading the optional unsigned iPhone IPA with a free Apple ID expires
  after 7 days (TestFlight builds do not require 7-day re-signing), and broader
  physical route/background/remote checks on iPhone remain open.
- Physical Apple Silicon Mac audio hardware validation remains open pending
  real-device testing.
- Bluetooth buffering can add delay. A classic Bluetooth headset microphone can
  switch audio to voice quality; LE Audio and hearing-aid coverage is limited.
- One active phone stream per desktop host is supported.
- Settings marked for the next connection require Stop/Connect in this build.
- Remote testing requires separate host/relay setup; it is not required for LAN.

Network RTT and buffer statistics do not measure physical audio delay.
Record unsupported hardware tests as skipped, with the reason.

First-party source is MPL-2.0. Recipients must receive access to the matching
source tag/commit (or an exact source snapshot) and applicable notices alongside
any distributed binaries.
