# MicDrop 0.1.0 — App Store & Google Play release candidate, in-app privacy links, and iPhone memory fix

This release promotes the shared MicDrop identity to `0.1.0` (build / Android
version code `6`) for Apple App Store and Google Play submission alongside
signed Windows 11 x64, Apple Silicon macOS 14.2+ arm64, and Linux x64 desktop
host packages. Check the generated **Package signing** line below and each
platform's `MicDrop-0.1.0-*-build.json` manifest for verified signing and
notarization status.

## Included in this release

- **iPhone iOS 17+ (`com.maskarauder.micdrop`, `0.1.0 (6)`)**:
  - Drains session worker autorelease pools across signaling retries, session
    waits, and `Stop` transitions to keep memory usage bounded during long
    listening/microphone sessions.
  - Adds a direct **Privacy policy** link (`https://maskarauder.com/micdrop/privacy/`)
    in **Diagnostics** alongside **Open-source notices**.
  - Drops the `-beta` version suffix from `MicDropVersionName` and increments
    `CFBundleVersion` to `6` for App Store Connect / TestFlight submission.
- **Android 12+ arm64 (`com.maskarauder.micdrop` Play AAB / `com.maskarauder.micdrop.dev` dev APK, `0.1.0` / `versionCode 6`)**:
  - Adds the signed, 16 KB page-size-verified Play Store `.aab` release
    pipeline, in-app **Privacy policy** link in **Diagnostics**, Play Store
    icon (`512x512`) and feature graphic (`1024x500`), and exact upload signing
    password handling.
  - Gates automated Google Play uploads on verified build results.
- **Desktop hosts (Windows 11 x64, Apple Silicon macOS 14.2+ arm64, Linux x64)**:
  - Hardens macOS notarization polling/evidence capture and Ubuntu APT mirror
    failover in CI while preserving Authenticode-signed Windows packages and
    Developer ID-signed, Apple-notarized macOS bundles when signing secrets are
    configured.
- MPL-2.0 license and third-party dependency notices in every packaged archive
  and application bundle.

Android version code is **6** (and macOS/iPhone `CFBundleVersion` is **6**).
Development APKs retain `com.maskarauder.micdrop.dev` so existing sideloaded
installations update in place, while Play Store `.aab` releases and iPhone
App Store / TestFlight builds use `com.maskarauder.micdrop`.

## Known limits

- Newly issued Windows Authenticode certificates build Microsoft SmartScreen
  download reputation gradually and may display an initial prompt until
  download volume accrues; Linux x64 archives remain unsigned.
- Phone microphone return requires a virtual audio cable (such as VB-CABLE on
  Windows, BlackHole on macOS, or a PipeWire/PulseAudio null sink + remap
  source on Linux) and explicit microphone permission on the phone.
- Bluetooth buffering can add delay. A classic Bluetooth headset microphone can
  switch audio to voice quality; LE Audio and hearing-aid coverage is limited.
- One active phone stream per desktop host is supported.
- Settings marked for the next connection require Stop/Connect in this build.
- Remote testing requires separate host/relay setup; it is not required for LAN.

First-party source is MPL-2.0. Recipients must receive access to the matching
source tag/commit (or an exact source snapshot) and applicable notices alongside
any distributed binaries.
