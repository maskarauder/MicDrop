# MicDrop 0.1.0-beta.2 — Windows, Android, and optional iPhone beta

This candidate is intended for volunteer beta testing on Windows 11 x64,
Android 12+ arm64, and optional sideloaded iPhone (iOS 17+ arm64). Build,
package, and smoke-test this candidate before sharing; these notes do not
record a successful build or new hardware acceptance.

## Included in this candidate

- Matching slate/gold Windows, Android, and iPhone interfaces.
- Phone **Diagnostics** with stream reports (plus Android crash reports), a
  local output check, and open-source notices.
- Windows per-user installer, portable package, tray controls, opt-in phone
  settings exchange, and configurable connection-log retention.
- Paired LAN playback, phone microphone return, and duplex with bounded
  network and Bluetooth route recovery. Remote access remains optional and
  separately configured.
- Optional unsigned iPhone (`iOS 17+` arm64) development IPA for Apple ID
  sideloading.
- MPL-2.0 license and dependency notices in the packaged applications.

Android version code is **3** (and iPhone `CFBundleVersion` is **3**). Both
mobile apps keep the provisional `com.maskarauder.micdrop.dev` identifier so
matching-signer updates preserve saved pairings and preferences. Preserve the
Android development signing key for subsequent beta updates.

## Before testing

Install the matching Windows setup executable and Android APK (or sideload the
unsigned iPhone IPA with your Apple ID) from this candidate. The portable
Windows ZIP is an alternative to setup. Follow the `BETA_TESTING.md` guide
supplied with the download.

Start with local-network playback on the phone speaker, then try your
headphones. Phone microphone return requires a separately installed Windows
virtual audio cable and explicit microphone permission on the phone.

## Known limits

- Windows packages are unsigned; publisher/reputation warnings may appear.
- Android is a sideloaded, debuggable development build, not a Play Store release.
- The iPhone package is an unsigned development IPA; free Apple ID signatures
  expire after 7 days and broader physical route/background/remote checks
  remain open.
- Bluetooth buffering can add delay. A classic Bluetooth headset microphone can
  switch audio to voice quality; LE Audio and hearing-aid coverage is limited.
- One active phone stream per Windows host is supported.
- Settings marked for the next connection require Stop/Connect in this build.
- Remote testing requires separate host/relay setup; it is not required for LAN.

Network RTT and buffer statistics do not measure physical audio delay.
Record unsupported hardware tests as skipped, with the reason.

First-party source is MPL-2.0. Recipients must receive access to the matching
source tag/commit (or an exact source snapshot) and applicable notices alongside
any distributed binaries.
